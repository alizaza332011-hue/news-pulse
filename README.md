# نبض الخبر | NEWS — التصميم الثاني

تصميم عربي متجاوب مستوحى من تنظيم المواقع الإخبارية الكبيرة: شريط أقسام، قصة رئيسية، آخر الأخبار، بطاقات أقسام، منوعات، فيديو، ومعلومات الثقة.

## المعاينة
افتح `index.html` في المتصفح. يحتاج اتصال إنترنت لتحميل خط Cairo وبعض الصور الخارجية.

## مهم
هذه واجهة تصميم فقط. النصوص والتوقيتات في البطاقات تجريبية وليست أخبارًا حقيقية، ولا يوجد حتى الآن ربط بمصادر RSS أو نظام نشر تلقائي أو نشرة بريدية. لا تنشر النماذج كما هي.

## رفع التحديث
ارفع الملفات الثلاثة (`index.html`, `styles.css`, `script.js`) إلى جذر مستودع GitHub بدل الملفات القديمة، ثم انتظر اكتمال النشر التلقائي على Cloudflare.
