# نبض الخبر | NEWS — النسخة الأولى
واجهة عربية متجاوبة (HTML/CSS/JS) بهوية أسود وذهبي وأوف وايت.

## معاينة
افتح `index.html` في المتصفح. لا تحتوي هذه النسخة على أخبار وهمية أو ربط RSS بعد.

## نشر مجاني على Cloudflare Pages
1. ارفع الملفات إلى مستودع GitHub.
2. افتح Cloudflare ثم Workers & Pages ثم Create application ثم Pages ثم Connect to Git.
3. اختر المستودع واترك أمر البناء فارغًا، واستخدم جذر المشروع كمجلد الإخراج.
4. بعد النشر تحصل على رابط مجاني ينتهي بـ pages.dev.

## المرحلة التالية
نحتاج تحديد مصادر RSS وشروط إعادة استخدام العناوين والملخصات والصور، ثم إعداد مهمة مجدولة لإزالة التكرار والتحقق من التاريخ والمصدر. النشر الآلي غير مفعّل في هذه النسخة. لا تضع مفاتيح API سرية في ملفات الواجهة أو مستودع عام.

قد تكون الاستضافة الثابتة مجانية، لكن بعض واجهات الذكاء الاصطناعي أو خدمات API قد تفرض رسومًا أو حدودًا.
