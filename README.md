# نبض الخبر | NEWS — نسخة مرتبطة بخلاصات الأخبار

## الملفات
- `index.html`, `styles.css`, `script.js`: واجهة الموقع.
- `worker.js`: واجهة API تجمع خلاصات RSS وتعرض العنوان والناشر والتاريخ ورابط المصدر.
- `wrangler.jsonc`: إعدادات Cloudflare Worker والملفات الثابتة.

## النشر
ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر مستودع GitHub واستبدل الملفات المتشابهة. يجب أن يكون أمر النشر `npx wrangler deploy` كما في إعدادك الحالي.

## ملاحظات تحريرية
هذه النسخة تعرض بيانات العناوين الواردة من Google News RSS وروابط الناشرين الأصليين؛ لا تنسخ نص المقالات ولا تدّعي التحقق المستقل من مضمونها. راجع الأخبار الحساسة قبل إعادة نشرها على منصات التواصل.

## التحديث
تُجلب الخلاصات عند فتح الموقع، مع تخزين مؤقت قصير على Cloudflare لتقليل الطلبات. لا يوجد حتى الآن نشر تلقائي على فيسبوك ولا نظام مراجعة إداري.
